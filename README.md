Step 1:

Install Node.js (LTS) – Download from nodejs.org, install, then confirm:

on your terminal :
    node -v    # should print a version

if it output a version that means your computer have it installed.


Step 2:

Cd your terminal all the way into the file root "sultanApp"
when you there run the command:

npm install

that will install all the depencies and create the node_modules folter and the package.json


Step 3

Run the command

npm run dev (for a dev envierment)

then on your browser do to localhost:30000 and you should have the app running
